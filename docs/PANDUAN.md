# Panduan BNI Optima

Panduan pengguna ada di tiga halaman web terpisah, dibagi per peran dan per tindakan ("Bagaimana ...?"):

- Anggota: `panduan/index.html` (https://mitologian.github.io/optima/panduan/)
- Launch Team: `panduan/lt/index.html` (https://mitologian.github.io/optima/panduan/lt/)
- LDC: `panduan/ldc/index.html` (https://mitologian.github.io/optima/panduan/ldc/)

Halaman anggota tidak memuat tautan ke halaman LT atau LDC. Ubah isi langsung di file masing-masing.
